EAS · ~20 dk

EAS ortam değişkenlerini tanımla

.env.local Git dışında kaldığı için cloud build bu üç public değeri EAS Environment’tan okur. Değerler .secret dosyanda var.

npm install --global eas-cli
eas login
eas whoami

# production ortamı (preview için aynı komutları --environment preview ile tekrarla)
eas env:create --name EXPO_PUBLIC_SUPABASE_URL --value "<SUPABASE_URL>" --environment production --visibility plaintext
eas env:create --name EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY --value "<PUBLISHABLE_KEY>" --environment production --visibility plaintext
eas env:create --name EXPO_PUBLIC_WEB_API_BASE_URL --value "<WEB_API_BASE_URL>" --environment production --visibility plaintext
⛔Asla EXPO_PUBLIC_* yapma: SUPABASE_SERVICE_ROLE_KEY · SUPABASE_SECRET_KEY · ADMIN_PANEL_PASSWORD · IP_HASH_SALT · GOOGLE_PLACES_API_KEY · service-account JSON. Bu prefix bundle içinden okunabilir.
📄Ayrıntı: docs/google-play/EAS_ENV_SETUP.md

7
Console · ~30 dk

Internal Testing’e manuel yükle

İlk yükleme manuel yapılır (EAS Submit otomasyonu sonraya). Internal test zorunlu değil ama AAB’nin Play dağıtımında çalıştığını kanıtlar.

💡Internal test için yalnızca kendin + 1–2 yakın kişi yeterli. Asıl 15–20 kişilik listeyi kapalı teste sakla — internal’daki kişi closed test sürümünü alamaz, önce internal’dan çıkması gerekir.
8
Zorunlu · 14+ gün

Closed Testing — kritik 14 gün

Kişisel hesapta production erişimi için en az 12 tester, 14 gün kesintisiz opted-in kalmalı. E-posta eklemek yetmez; herkes opt-in linkinden katılıp uygulamayı Play’den kurmalı ve testten çıkmamalı.

⏳Bu süre paralel değerlendirilebilir: 14 gün beklerken 9–10. adımları (store listing + beyanlar) tamamla. Hata düzeltip yeni AAB yükleyebilirsin — yeter ki testerların opt-in durumu bozulmasın.

Sonrası: opsiyonel EAS Submit otomasyonu

Sonraki sürümlerde eas submit --platform android --profile production ile otomatik yükleme kurabilirsin. Bunun için Google Cloud service-account JSON key gerekir — asla repoya commit etme, EXPO_PUBLIC’e koyma, mesajlaşma uygulamalarında paylaşma. eas credentials --platform android ile EAS’a yüklenir. (Secret taraması bu dosyaları zaten yakalıyor.)
