# Closed Test Plan

## Strateji

- İlk doğrulama için `Internal test` açılması önerilir.
- Kişisel Play Console hesabı ile production başvurusu öncesi `Closed test` zorunluluğu dikkate alınmalıdır.
- Minimum `12` opted-in tester hedeflenmelidir.
- Testerların en az `14 gün` kesintisiz opted-in kalması gerekir.
- Güvenli marj için `15–20 tester` önerilir.

## Test senaryoları

- Ana sayfa
- Haberler
- Haber kaynak bağlantısı
- Türkçe hizmet rehberi
- Hizmet sağlayıcı önerme
- Kırık bağlantı bildirme
- Vatandaşlık testi
- Maaş hesaplayıcı beta uyarısı
- İş ilanları
- Harici link açma
- Offline davranış
- Android geri tuşu
- Farklı ekran boyutları
